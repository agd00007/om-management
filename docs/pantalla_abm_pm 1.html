❓ Ayuda · Cómo funciona este ABM

✕
Empresa: se pueden dar de alta todas las empresas con faceta / tipo de prestador "Am" (ambulancia). Cada versión de %OM queda con fecha de vigencia: la versión vigente anterior de esa empresa, para el mismo Tipo de Servicio, se cierra automáticamente el día previo a la nueva fecha de inicio, sin perder el historial (por ejemplo, si Acudir pasara de 60% a 51% en Emergencia a partir de una fecha dada, la versión del 60% quedaría cerrada el día previo).
Tipo de Servicio: todo %OM se define a nivel Tipo de Servicio (por ejemplo, Emergencia o Traslado). Cada Tipo de Servicio es un universo de %OM independiente de los demás: la suma de los %OM vigentes de todas las empresas no debe superar el 100% dentro de ese mismo Tipo de Servicio, pero una empresa puede tener %OM cargado a la vez en varios Tipos de Servicio distintos (por ejemplo, Acudir tiene 60% en Emergencia y 70% en Traslado, cargados por separado). Una empresa puede no tener todavía ningún %OM cargado para algún Tipo de Servicio puntual (por ejemplo, URG no tiene Traslado cargado): es un estado válido, y no le impide tener %OM en otros Tipos de Servicio. No aparece en el listado para ese Tipo de Servicio hasta que se le dé de alta una versión ahí desde Nueva Versión, que es la única forma de cargar versiones nuevas.
Nueva Versión: permite cargar, en una misma tanda, una nueva versión de %OM para uno o varios Tipos de Servicio a la vez (por ejemplo, Emergencia y Traslado juntos), todas vigentes desde la misma fecha — pero el %OM se define por separado para cada Tipo de Servicio elegido, en su propia grilla de Empresa / %OM actual / %OM nuevo. El control del 100% se aplica sobre el total combinado de la carga dentro de cada Tipo de Servicio por separado. Toda la carga (con todos los Tipos de Servicio que incluya) queda identificada con un único N° de versión correlativo, visible en la columna "N° Versión" del listado (la carga inicial de datos es la versión N° 1).
Editar versión: usa el mismo diseño que Nueva Versión — corrige, para todas las empresas de un mismo N° de versión a la vez (agrupadas por Tipo de Servicio), su %OM y/o su fecha de vigencia (no genera una versión nueva, ni cambia el N° de versión ni el o los Tipos de Servicio). El control del 100% se aplica igual que en Nueva Versión, por separado en cada Tipo de Servicio incluido.
Borrar versión: elimina de una sola vez todos los registros que comparten un mismo N° de versión (por ejemplo, toda una carga, con todos sus Tipos de Servicio), en todas las empresas donde se haya cargado esa versión. Si a alguna empresa la deja sin ningún %OM cargado para algún Tipo de Servicio puntual, el sistema lo avisa antes de confirmar (ese estado es válido: es el mismo con el que arranca una empresa antes de su primera carga en ese Tipo de Servicio; puede seguir teniendo %OM cargado en otros).

Editar versión completa de %OM

Se editan de una sola vez los valores de todas las empresas que comparten este N° de versión (no se crea una versión nueva ni cambia el N° de versión). El %OM se define por separado para cada Tipo de Servicio incluido en esta versión, y el control del 100% se aplica igual que en Nueva Versión, dentro de cada uno.

Nueva Versión · %OM por Tipo de Servicio

Pasá a la derecha uno o varios Tipos de Servicio para cargarles %OM en la misma tanda (por ejemplo, Emergencia y Traslado a la vez). El %OM se define por separado para cada Tipo de Servicio elegido, más abajo.

El %OM nuevo arranca en 0 para todas las empresas; ajustá el valor de las que querés actualizar y dejá en blanco (borrá el campo) las que no cambian en esta carga, para excluirlas. A cada empresa con un valor cargado se le crea una nueva versión vigente desde la fecha indicada, para el Tipo de Servicio de su grilla — su versión anterior en ese mismo Tipo de Servicio se cierra automáticamente el día previo. Todas las empresas actualizadas en esta carga, en todos los Tipos de Servicio incluidos, comparten el mismo N° de versión y la misma fecha de vigencia.

El total de %OM vigente tiene que sumar exactamente 100% en cada Tipo de Servicio incluido — si suma menos o más, no se puede guardar.
